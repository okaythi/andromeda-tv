# Security Policy

## Supported Versions

We actively support the latest pre-release/release versions and the master branch with security updates.

| Version          | Supported          |
| ---------------- | ------------------ |
| 0.1.x / alpha    | :white_check_mark: |
| master           | :white_check_mark: |
| < 0.1            | :x:                |

---

## Rewards & Bounty

We greatly appreciate the security research community’s help in keeping Andromeda TV secure.

- **Reward:** As a token of appreciation, any researcher or user who reports a **confirmed, valid, and previously unknown vulnerability** following our responsible disclosure process will receive **3 months of free service**.
- **Eligibility:**
  - You must be the first person to report the specific vulnerability.
  - You must not publicly disclose or exploit the vulnerability prior to a resolution.
  - Testing must adhere to standard ethical guidelines (avoid denial-of-service, privacy violations, or destruction of data).

---

## Reporting a Vulnerability

If you discover a potential security vulnerability, please disclose it to us responsibly.

### How to Report

Please **do not** report vulnerabilities through public GitHub issues or discussions.

1. **GitHub Security Advisory (Recommended):**  
   Submit a private report via the [Security Advisories page](https://github.com/okaythi/andromeda-tv/security/advisories/new).
2. **Direct Contact:**  
   If the advisory interface is not accessible, contact maintainer [@okaythi](https://github.com/okaythi) privately via GitHub.

### What to Include

To help us validate and triage your report promptly, please include:

- A description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- The affected component, version, and platform/OS (Windows, macOS, Linux, etc.).
- Contact details (or your Andromeda TV account info) so we can grant your 3-month reward upon confirmation.

### Response & Resolution Timeline

- **Acknowledgment:** Within **48 to 72 hours**.
- **Triage & Validation:** We will investigate and confirm whether the issue qualifies for the 3-month reward.
- **Coordination & Release:** Once resolved, we will publish the fix and coordinate credit/acknowledgments in the security advisory.
